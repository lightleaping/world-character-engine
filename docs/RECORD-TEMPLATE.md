# 미션·평가 기록 양식

## 미션 기록

```text
날짜 / 미션:
목표와 완료 기준:
내가 직접 작성·수정한 코드:
참고 코드·AI 도움:
환경 / 실행 명령 / 입력:
실제 결과 / 로그:
실패와 수정:
내 설명과 리뷰 결과:
독립적인 변경 과제와 결과:
공개 가능한 증거 / 커밋:
다음 미션:
```

## 실험·서비스 평가

```text
평가 질문:
데이터 출처·버전·표본 수 또는 API 시나리오:
Train/Validation/Test 분리 또는 테스트 조건:
기준선 / 변경점:
환경·시드·모델·커밋:
지표 정의:
실제 결과 파일:
실패 사례·한계:
```

모델 지표와 API 테스트 통과를 구분한다. 미측정 값은 미측정으로 남기고 기존 프로젝트 결과를 가져오지 않는다.
