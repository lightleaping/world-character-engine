# 미션 01 — 캐릭터 상태와 행동 정의

## 목표
캐릭터 1명과 작은 세계의 상태·허용 행동을 정한다.

## 사용자가 직접 정할 것
1. 세계관과 캐릭터 페르소나.
2. 장소와 현재 위치, 소지품 등 상태 필드.
3. 처음 허용할 행동 3개 안팎.
4. 행동마다 필요한 조건과 실패 시 결과.
5. 기억해야 할 사건과 저장하지 않을 정보.
6. 정상 대화·없는 기억·실행 불가능한 행동의 예시.

## 완료 기준
제안된 행동과 실제 상태 변경을 구분해서 설명한다. 캐릭터 설정을 AI가 임의로 확정하지 않는다.
XR은 범위에서 제외한다. LangGraph 도입은 상태·분기 관리 필요를 확인한 뒤 결정한다.
다음 후보 미션: 구조화 응답과 Python 상태·행동 검증.
