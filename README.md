## 해결하려는 문제

대화가 이어져도 캐릭터의 설정과 기억이 유지되고, 말로 제안한 행동이 실제 세계 상태와 일치하도록 만드는 프로젝트입니다.

| 입력 | 목표 출력 |
|---|---|
| 사용자 발화, 페르소나, 기억, 현재 세계 상태 | 캐릭터 응답, 검증된 행동 결과, 갱신된 상태와 기억 |

## 구현할 흐름

```text
입력·상태 → 기억 검색 → 행동 제안 → 코드 검증 → 실행 → 응답·기억 저장
```

- 캐릭터 1명과 작은 세계의 페르소나·상태 정의.
- 단기 대화와 장기 기억 검색.
- 구조화된 행동 제안, 실행 검증, 실패·중복 처리.

**적용 예정 기술:** Python · LLM · RAG · FastAPI, 필요에 따라 LangGraph  
기술 목록은 설계 방향이며 현재 구현 완료 목록이 아닙니다.

## 검증할 내용

- 기억 검색과 근거 없는 기억 생성 여부.
- 상태 일관성과 유효하지 않은 행동의 실행 방지.
- 도구 실패·중복 요청·사용자별 기억 분리.

XR은 제외합니다. LLM의 행동 제안은 프로그램이 유효성을 검사한 뒤 실행하도록 설계합니다.
