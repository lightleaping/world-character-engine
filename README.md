# 세계관 AI 캐릭터 엔진

**Python · 상태 관리 · 행동 검증 · LLM/Agent 기반 설계**

캐릭터의 현재 상태와 행동 선행 조건을 코드로 관리하고, 제안된 행동을 검증한 뒤 성공한 실행만 상태에 반영하는 작은 AI 캐릭터 엔진입니다.

> **현재 단계 · 1회차 상태·행동 엔진 구현 완료**
> 결정론적 Python 엔진과 13개 회귀 테스트를 구현했습니다. LLM과 장기 기억은 아직 연결하지 않았습니다.

## 해결하려는 문제

대화가 이어져도 캐릭터의 설정과 기억이 유지되고, 말로 제안한 행동이 실제 세계 상태와 일치하도록 만드는 프로젝트입니다.

| 입력 | 목표 출력 |
|---|---|
| 사용자 발화, 페르소나, 기억, 현재 세계 상태 | 캐릭터 응답, 검증된 행동 결과, 갱신된 상태와 기억 |

## 현재 구현 흐름

```text
구조화된 행동 제안 → 허용 목록 검증 → 상태 조건 검사 → 실행 → 상태 변경 → 결과 기반 응답
```

- 새로운 세션·테스트마다 독립적인 초기 상태를 생성합니다.
- 미지원·누락 행동을 실행 전에 차단합니다.
- 도구가 성공한 경우에만 상태를 변경합니다.
- 완료된 서류 정리와 중복 이동을 거절합니다.
- 검증된 실행 결과를 캐릭터 대사로 변환합니다.

**현재 기술:** Python 표준 라이브러리
**다음 단계:** OpenAI API 구조화 응답 · 최근 대화 상태 · 장기 기억 검색

## 실행

별도 패키지 설치 없이 Python 3.9 이상에서 실행할 수 있습니다.

```bash
python test_character_engine.py
```

현재 기대 결과:

```text
모든 테스트 통과: 13개
```

## 확인한 동작

- 서류 정리 성공, 도구 실패, 잘못된 장소, 작업 중 상태.
- 행동 누락, 미지원 행동, 행동 없는 대화.
- 이동 선행 조건과 중복 이동 차단.
- 거절·실패 시 상태 불변과 결과에 맞는 대사.

장기 기억 검색, 근거 없는 기억 생성 평가, 사용자별 기억 분리는 아직 구현하지 않았습니다. XR은 범위에서 제외합니다.
